# Changelog

All notable changes to RF Canvas are documented in this file.

## [1.0.0] - 2026-10-01

### Added
- Passive Sub-GHz RF activity monitoring
- 315.000 MHz, 433.920 MHz and 868.350 MHz scanning
- Automatic and manual frequency selection
- Adaptive RSSI baseline calibration
- RSSI, delta, peak and event counters
- High / Medium / Low sensitivity modes
- Hysteresis-based RF event detection
- Analyze, Art and Hybrid display modes
- Conway's Game of Life generative visualization driven by RF activity
- Custom Flipper Zero application icon
- Persistent FAP installation under Apps → Sub-GHz
- Repository documentation and screenshots

### Scope
- Passive receive-only RF activity visualization
- No replay, cloning, protocol cracking or device impersonation features
